- 只隐藏进入时捕获且验证过的原生二级导航 wrapper；后插入的其他组件二级导航保持可见，不以「不是本组件节点」作为批量隐藏条件。如果真实环境出现视觉冲突，针对已识别的组件另议兼容，不预先隐藏未知兄弟节点。
