# 接管只校验实际操作边界，不确认宿主页面形状

隐藏与恢复不需要认识正文内部结构。兄弟组件插入列、排序条或把昵称链接换为文本，不应让帖子视图拒绝工作。接管以正文与 footer 的可靠边界为依据，校验必须能说明不确认它将导致的具体错误操作；展示与可选几何目标缺失采用降级，不作为挂载门槛。不为兄弟组件枚举页面形状或增加白名单例外。

只在入口插入与进入帖子视图时校验，不在活动期间重新判断宿主结构、自动退出或重新接管。这是有意的取舍：不与其他组件争夺页面控制，代价是不承诺活动期间任意 DOM 改动后的布局完好或自动修复。正常退出仍须可逆恢复并尊重外部修改，异步数据仍受路由与请求归属控制；这些职责不等于运行期宿主守卫。当前行为统一维护在 [宿主规格](../spec/host-view.md)。
