# 冻结分类页与有限分段预加载

SearchEncore 是动态索引，无快照与稳定游标承诺，重复抓取也无法保证找回遗漏。项目选择**已展示内容稳定、后续浏览提前准备**：冻结实际展示页，晚到内容仅按分类排除；允许有限分段预加载确认更多可跳转页，但不把预加载等同于展示或冻结。已在缓存中的未访问页内容不是晚到内容，跳页不能把它们排除。

## Considered Options

- 只准备当前页和一条前瞻：请求最少，但使页码增长依赖逐页访问，远距浏览成本过高。
- 有限分段预加载：采用——当前页可靠就展示，后续目标由用户翻页扩展，兼顾首屏可用与连续浏览。
- 无限滚动 / 抓全部历史：拒绝——超出用户已触发的有限目标，请求量不可预测。
- 后台重扫修复 offset 漂移：拒绝——请求不可控放大，且动态索引下仍无法保证完整。

## Consequences

- 接受动态索引下的可能遗漏；新增内容经整页刷新获取，不承诺找回所有历史。
- 服务游标进展、有效内容进展和请求重试是不同问题；成功响应不能充当有效新增，空转暂停不能冒充读尽。
- 当前加载、请求调度、重试与冷却的唯一规则来源是 [`../spec/feed.md`](../spec/feed.md)，不能把这些边界当作任意调优参数。
