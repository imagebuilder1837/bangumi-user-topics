# 冻结分类页与一条前瞻的有限调度

SearchEncore 是动态索引，无快照与稳定游标承诺，重复抓取也无法保证找回遗漏。项目选择**展示稳定性与可预测行为优先于数据完整性**：各分类冻结已展示页的身份序列、晚到内容仅按分类排除（共享缓存保留首次接收数据）、合并前要求每流足够有效前缀或自然读尽、用一条前瞻（前缀 +1 候选）三态判断下一页、游标只按原始服务分页进度推进、调度上全局 3 并发/每流 1/每目标每流 3 次/15 秒超时/429 全局暂停且不自动恢复，不做后台 offset 重扫、不预取完整页、不抓全部历史。

## Considered Options

- 后台重扫修复 offset 漂移：被拒——请求不可控放大，且动态索引下仍无法保证完整。
- 无限滚动 / 完整下一页预取：被拒——与“仅完成用户已触发的有限目标”的边界冲突。

## Consequences

- 接受动态索引下的可能遗漏；新增内容经整页刷新获取，不承诺找回所有历史。
- 并发数、预算、超时与冷却参数是边界语义的一部分，不是可随意“优化”的调优项；调整需同步修订 `docs/spec/feed.md`。
