# 帖子视图与交互

## 独立页面

- 帖子呈现为统一独立单列布局（最大 1200px 外框内最大 750px 正文，见 [`host-view.md`](host-view.md)），不沿用宿主页列宽、不展示旧日志标签或收藏统计侧栏。
- 不在帖子根复用会预留侧栏空间的 `columns-center` 布局；复用的是原生列表、标题、metadata、导航与分页 class，不复制宿主 ID，不建立自定义主题体系（暗色/窄屏由原站 CSS 变量与规则承接）。

## 导航与标题

- 二级导航提供“全部帖子 / 小组话题 / 条目讨论”，对应三个分类 hash。
- 页面标题为目标用户昵称的帖子；昵称取自 `#headerProfile h1 .name > a` 锚点文本，不拼入 @username、按钮或整个标题容器文本。

## 列表条目

- 每条显示主题标题、所属来源、创建时间及回复数；不显示正文摘要，不为摘要增加逐条详情请求。
- 链接均保留当前域名、普通当前标签打开，保留 Ctrl/中键等浏览器修饰键行为。
- 主题链接由来源与主题 ID 构造；所属对象链接：小组 `/group/{parentID}`（不加尾斜杠）、条目 `/subject/{parentID}`。不查父对象详情、不把 parentName 显示名当 slug。
- 降级文案：空标题显示“无标题”；来源名称缺失显示“小组话题”或“条目讨论”；零回复正常显示。时间按 Unix 秒解析，以 UTC+8 显示 `YYYY-M-D HH:mm`。

## 分页

- 仅上一页、下一页及当前页码；不显示总页数、不支持跳页。加载目标页时禁止重复翻页，但允许切分类或离开。
- 下一页入口按三态呈现（有 / 读尽 / 未知）；错误、预算不足、检索上限与未知不得共用误导性的“没有更多”文案。

## 状态文案

- 加载：简洁的原生风格文字提示。
- 空结果：“没有找到已收录的帖子”——不得断言该用户从未发帖。
- 错误：提供错误信息与针对目标页的重试；不宣称从未发帖。
- 检索上限：“已达到服务检索上限，可能仍有更早的帖子”，不绕过限制。

## 滚动与焦点

- 显式点击进入、切分类后使帖子标题可见；成功翻页后使列表顶部可见；失败留在原处不滚动。
- 后台任务完成或失败不抢键盘焦点、不滚动、不弹提示。加载与错误状态提供辅助技术可读提示，不强抢焦点。
- 宿主页滚动快照只在从宿主进入时保存，切分类不覆盖；同文档退出尽量恢复进入前位置，其他有效原生锚点优先。浏览器历史变化（前进/后退）不套用显式点击的滚动规则；响应到达时需确认用户意图，不在用户已离开后滚动。
