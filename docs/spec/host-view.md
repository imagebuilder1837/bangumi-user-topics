# 宿主接管与路由

## 入口出现范围

- 入口按路径确定作用范围，与正文接管校验解耦（见 [`../adr/0003-entry-scope-decoupled-from-takeover.md`](../adr/0003-entry-scope-decoupled-from-takeover.md)）：匹配 `/user/{key}`（`blog`、`index`、`friends`、`rev_friends`、`timeline`、`mono`、`groups`、`wiki` 之一级段及任意深度子路径）、`/{anime|book|music|game|real}/list/{key}`（含单个状态子路径）；不匹配 `doujin`、未知一级段及未知 list 子路径。
- 范围外，或无法识别个人页头内的一级导航时静默退出：不插入口、不显示错误面板、不输出挂载失败警告、不请求 API。宽泛 metadata 不等于所有匹配页面都应有入口。

## 入口插入与身份

- 在个人页头内的 `.navTabs` 中，通过同源 `/user/{key}/blog` 日志链接定位导航项，在其后插入“帖子”。不依赖日志链接是导航项的首个元素，不要求固定的中间 wrapper 层级，不复制或克隆宿主导航。
- 用户 key 为日志链接与页面路径共同确认的用户名或数字 UID，按解码后的身份比较，不因等价 URL 编码拼写不同而拒绝。同一目标的重复日志项取第一个作为插入锚点，真实身份冲突才拒绝。
- key 必须可解码、非空且适用于用户查询；作为 URL 参数编码。不转换为 UID，不回退到当前登录用户，不把昵称或页面文本当查询指令，不为改名追加搜索。
- 插入必须幂等；自有节点使用稳定的 `data-*` 身份标记，只拥有和修改本组件节点。入口插入不检查正文、不请求 API、不改变 hash。

## 路由

- 仅四个精确 hash 有效：`#posts`、`#posts/group`、`#posts/subject`、`#posts/replies`。其他 hash 不接管、不清理；pathname 与 query 保持不变，不创建虚假的服务器路径。
- `location.hash` 是分类的唯一真值。初始化处理直接打开的有效 hash，后续处理 `hashchange`。挂载失败后再次点击同 hash 的入口也必须能重试，不能只依赖 `hashchange`。
- 翻页不新增浏览器历史、不把页码写入 URL。四分类各自记住最近访问页；分享链接从对应分类第 1 页打开。不承诺帖子视图内的历史滚动恢复。
- 不新增“返回原页面”入口，不全局拦截原生导航；原生整页跳转与同文档 hash 退出是不同路径。

## 校验与失败提示

- 校验仅在插入入口、从宿主页进入帖子视图两个时点执行；后者包含深链初始化、退出后重入、失败重试。帖子内部切分类、翻页、请求完成、已显示时重复点击入口，不重新校验宿主。
- 激活检查当前目标身份，以及个人页头之后真实正文 `.mainWrapper` 与其直接 footer 的可靠边界。正文不必紧邻页头，不要求 `.columns`、内容锚点或已知页面形状；不能误把页头之前的空 `#main` 当正文，也不能隐藏个人导航或 footer。挂载边界存在歧义时不接管。
- 昵称链接、站点顶栏、原二级导航都是可选目标，缺失不阻断整个组件。原二级导航可定位时捕获第一个合适 wrapper；多余 wrapper 不阻止接管，不能隐藏包含一级导航的 wrapper。
- 已识别个人导航后，入口插入或激活失败必须在其附近显示独立错误面板，内容为“失败阶段 + 本次首个实际阻断原因”，并在控制台补充原因与定位信息。不能只显示宽泛的“无法安全挂载”。失败不隐藏或重建宿主、不发起本次查询、不改 hash；已经发出的有限请求可完成。
- 重复失败更新同一面板，不堆叠；重试成功后移除。激活错误在离开帖子 hash 时撤销。若重新进入时个人导航已不可识别，按范围规则静默退出，不提供全页兜底提示。

## 接管与恢复

- 采用 hide + sibling：正文内 footer 之前的宿主元素（含旧正文、侧栏及兄弟组件内容）临时隐藏，在 footer 之前插入自有帖子根。header、个人导航、footer 不销毁、不隐藏；不移动、克隆或重建宿主。兄弟组件增加正文形态不需要白名单例外，理由见 [`../adr/0004-footer-boundary-takeover.md`](../adr/0004-footer-boundary-takeover.md)。
- 原二级导航只隐藏进入时捕获的合适 wrapper，隐藏整个 wrapper 而非内部列表。后插入的其他二级导航保持可见，不以“不是本组件节点”为由批量隐藏。
- 显示控制绑定到已定位节点的自有标记，不依赖宿主固定祖先层级、原 class 或 ID 持续不变。隐藏必须压过原站显式 display 规则，不能假定 hidden 属性生效。禁止通过 innerHTML 或 clone/替换宿主正文切换视图。
- 恢复只撤销仍由本组件控制的属性和状态，不整体回写旧 class/style，不覆盖已观察到的外部修改；已删除的宿主节点不复活。

## 几何与 focus

- 帖子是独立单列页面：最大 1200px 流式外框内的最大 750px 居中正文。仅活动期间对已定位的正文做有限宽度归一化；可定位的 `#wrapperNeue` 与站点顶栏另作可逆 min-width 覆盖，不以它们缺失为挂载门槛。不改 mainXL class、不复制宿主 ID、不全局覆盖任意容器。
- 祖先宽度覆盖的理由是原站在部分视口下有 1000px 最小宽度，见 [`../external/bangumi.md`](../external/bangumi.md)。缺失可选几何目标时跳过相应操作，不保证第三方完全改写布局后的几何一致性。
- 进入时移交已选中顶层导航项的 focus，包括其他扩展创建的项；只改 focus token，不改内容、不删除、不循环争抢。退出时外部焦点修改优先，只恢复仍持有的状态。
- 键盘焦点捕获范围是本次隐藏的正文元素，不依赖 `.columns`。退出不抢走用户后来选择的控制焦点，不聚焦已删除或已移出原正文的节点。

## 活动期与重入

- 不设运行期宿主结构守卫：DOM、class、ID、标记变化不会触发重新校验、自动退出、报错或自动修复；异步发布前也不复核宿主结构。活动期被其他组件破坏布局，不承诺实时恢复。
- 正常路由退出仍清理自有视图、导航与样式并尽可能恢复宿主。下次进入使用当前节点重新校验，成功后才接管，不主动滚动。
- 恢复所有权观察与请求生命周期控制保留，但不用于监控宿主结构或争抢页面。迟到请求不重开视图、不提交后台可见页码、不抢焦点或滚动；同一目标的任务与缓存可在重入后复用，不同用户的数据不可混用。
