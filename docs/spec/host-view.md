# 宿主接管与路由

## 入口插入

- 在用户页一级导航的原生日志链接（`#headerProfile .navTabs` 中 `li > a[href="/user/{key}/blog"]`）之后插入“帖子”入口；通过语义 href 定位，不依赖子节点序号，不依赖其他扩展存在。
- 插入必须幂等；扩展节点使用稳定的 `data-*` 身份标记，只拥有和修改本组件自己的节点。不复制的宿主节点、不克隆整条导航。
- 目标用户 key 从原生日志链接取得；用户名或数字 UID 均直接使用，不转换为 UID，不回退到当前登录用户，不为改名做多次搜索。key 按 URL 参数编码，且必须先通过身份与页面范围校验；不把标题或任意页面文本当查询指令。

## 路由

- 仅三个精确 hash 有效：`#posts`、`#posts/group`、`#posts/subject`。其他 hash 不接管、不清理；pathname 与 query 保持不变，不创建虚假的服务器路径。
- `location.hash` 是分类的唯一真值。初始化处理直接打开的有效 hash；后续处理 `hashchange`。同 hash 的再次点击不必然产生该事件，不能依靠事件重复触发维持必要行为（如结构失效后重入）。
- 翻页不新增浏览器历史、不把页码写入 URL。三个分类各自记住最近访问页；分享链接从对应分类第 1 页打开。不承诺帖子视图内的历史滚动恢复。
- 不新增“返回原页面”入口，不全局拦截原生导航；原生链接的整页跳转与同文档 hash 退出是不同路径。

## 安全挂载

- 接管前确认：个人导航可识别、目标用户 key 可靠取得、原正文 columns 及其与 footer 的结构关系成立。
- 无法安全挂载时不插入入口、不隐藏宿主、不请求 API、不改 hash；直接打开有效帖子 hash 也一样，仅留简短控制台诊断。

## 接管与恢复

- 采用 hide + sibling：原正文与旧侧栏整体临时隐藏（原节点、listener、状态与其他组件内容全部保留），在原 columns 同父位置、footer 之前插入自有帖子根。header、个人导航、footer 不被销毁；不移动、克隆或重建宿主。
- 原二级导航只隐藏进入时捕获且验证过的 wrapper（隐藏整个 wrapper 而非内部列表，因其自带背景和边框）；后插入的其他组件二级导航保持可见，不以“不是本组件节点”作为批量隐藏条件。禁止隐藏同时包含一级导航的 `.subjectNav`。
- 隐藏机制必须实际压过原站显式 `display` 规则，不能假定设置 `hidden` 属性必然生效。禁止用 `innerHTML` 或 clone/替换宿主正文实现视图切换。
- 恢复时只撤销仍由本组件控制的属性与状态，不整体回写旧 class/style 字符串，不覆盖已观察到的外部修改。

## 几何覆盖

- 帖子呈现为独立单列页面：同一视口下观感不因入口宿主页改变；统一为最大 1200px 流式外框内的最大 750px 居中单列。
- 仅在帖子活动期、通过自有活动标记，对已验证节点（`#wrapperNeue`、`#headerNeue2` 的 min-width，正文父 `.mainWrapper` 的 width/max-width/min-width/margin/padding/box-sizing）做有限可逆归一化。不改宿主 `mainXL` class、不复制宿主 ID、不全局覆盖任意容器；退出时撤销本组件持有的覆盖。
- 必要性来自原站 CSS：非 mainXL 宿主页在 641–999px 视口仍有 1000px 祖先最小宽度，仅设置自有根宽度无法兑现跨入口一致（见 [`external/bangumi.md`](../external/bangumi.md)）。

## focus 与共存

- 允许对宿主显示状态和导航 focus 做有限可逆修改。进入时将已选中的顶层导航项移交 focus，包括其他扩展创建的项；只改 focus token，不改其内容、不删除节点、不循环争抢。
- 退出时仅恢复仍由本组件控制的状态；外部修改优先。

## 失效与重入

- 运行期守卫检查已确认的宿主节点关系、原正文隐藏所依赖的关键 class、本组件活动标记及相关节点属性变化；异步结果发布前再次复核。局部 DOM 守卫不承诺实时侦测任意全站样式表变化。
- 原 `columns` 失去隐藏条件时退出接管并恢复可恢复状态；不因 DOM 恢复而自动重新接管，保留有效 hash。
- 经完好入口显式重入必须再次执行安全检查，通过后方可进入；挂载成功后不主动滚动。宿主未恢复时守卫早退，不滚动、不接管、不重建宿主。
- 失效期间已触发的有限请求可以完成，同一目标用户的成功数据仍可缓存；不得因此发布旧视图、页码、焦点或滚动。重入后按当时的分类与页码重新判断，不兑现退出前排队的可见操作。
